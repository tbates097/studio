Orthogonality Chart Test

This test shows the correct format for orthogonality measurement display:

  • X-axis (Direction 1): Measurement distance/travel
  • Y-axis (Direction 2): Perpendicularity error (deviation from perfect perpendicularity)
  • Red line: Reference measurement (shows artifact's own error/slope)
  • Blue line: Best-fit line through actual measurements (orthogonality error)
  • X markers: Individual measurement points
Error Exaggerated 10000X

Chart Interpretation:

Blue Line: Reference measurement slope (artifact error) - shows the reference face is not perfectly flat
Red Line: Best-fit through actual measurements (orthogonality error) - shows the perpendicularity deviation
X Markers: Individual measurement points taken during the test

True Orthogonality Error: The angle between the red and blue lines shows deviation from perfect 90° orthogonality. Perfect orthogonality would show these lines at exactly 90° to each other.
