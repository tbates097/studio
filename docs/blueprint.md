# **App Name**: OrthoPrecision

## Core Features:

- Live Data Stream: Real-time data acquisition from digital indicator via serial communication.
- Precision Calculation: Calculates orthogonality in arcseconds (if measurement distance > 100mm) or microns (if measurement distance <= 100mm).
- Modern UI/UX: Presents measurement data and calculated orthogonality in a clear, modern user interface with live feedback.
- PDF Report Generation: Generates a PDF report of the measurement results.

## Style Guidelines:

- Primary color: Dark blue (#2E3A59) for a professional and precise feel.
- Secondary color: Light gray (#E5E8EF) for background and subtle contrast.
- Accent color: Teal (#008080) to highlight key information and interactive elements.
- Headline font: 'Roboto' for clear and modern headings.
- Body font: 'Open Sans' for easy readability of measurement data and reports.
- Use clean, minimalist icons to represent actions and data types.
- Structured layout with clear visual hierarchy for easy navigation and data interpretation.
- Subtle transitions and animations to provide live feedback and a smooth user experience.
